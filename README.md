# Pulsolux – Webseite

Download-Seite für die Android-App **Pulsolux** (IDPA-Projekt, Gruppe 6, IM24a, bwd Bern, Schuljahr 2026/27).
Testpersonen können hier die APK für den Gerätetest herunterladen.

## Entwickeln

```bash
npm install
npm run dev
```

`npm run build` erstellt die statische Seite in `dist/`. Veröffentlicht wird über Vercel.

- APK: `public/pulsolux.apk` (Version und Datum in `src/App.tsx` oben anpassen)
- Screenshots: `public/screenshots/1.png` bis `3.png` (optional, sonst gezeichnete Vorschau)

Webseite mit Unterstützung von Claude Code erstellt.
